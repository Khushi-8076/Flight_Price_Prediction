# ✈️ Flight Price Prediction

## 📌 Project Overview
The Flight Price Prediction project focuses on analyzing flight booking data and preparing it for machine learning to predict ticket prices. It involves data cleaning, exploratory data analysis (EDA), and feature engineering using Python.

## 🎯 Objectives
- Analyze flight price data and identify important patterns.
- Clean the dataset and handle missing values.
- Perform exploratory data analysis (EDA).
- Prepare features for machine learning.
- Develop a regression model to estimate flight ticket prices.

## 🛠️ Technologies Used
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Tools:** Jupyter Notebook, GitHub
- **Machine Learning:** Scikit-learn (for model training, when implemented)

## 📂 Project Files
- `flight_price.ipynb` — Jupyter Notebook containing data analysis and project workflow.
- `flight_price_data.xlsx` — Dataset used for analysis.
- `README.md` — Project documentation.

## 🔍 Project Workflow
1. Data loading and inspection
2. Data cleaning and missing-value handling
3. Exploratory Data Analysis (EDA)
4. Feature engineering and data preprocessing

## 📊 Key Learnings
- Data preprocessing and cleaning
- Exploratory data analysis
- Feature engineering
- Preparing data for predictive modelling

## 🚀 How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/Khushi-8076/Flight_Price_Prediction.git
   ```
2. Open the project folder.
3. Install the required libraries:
   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn openpyxl
   ```
4. Open `flight_price.ipynb` in Jupyter Notebook.
5. Run the notebook cells in sequence.
